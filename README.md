# Edgar & Nina Timeline

A warm, nostalgic timeline site documenting the relationship arc of Edgar and Nina from their first conversations through 2026.

## Run locally

From the project root:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Files

- `index.html` — page structure and content
- `styles.css` — design, layout, dark romantic aesthetic, and responsive behavior
- `script.js` — timeline data rendering, scrolling effects, and interactions
